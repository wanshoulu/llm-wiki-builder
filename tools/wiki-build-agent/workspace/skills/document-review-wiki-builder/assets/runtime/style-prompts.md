# 公文语言风格提示

## 通用

语言应准确、简明、庄重，避免口语化、情绪化、夸张化和无法验证的绝对化判断。涉及强制要求时保持来源原文，不自行强化或弱化。

## 通知

说明事项、对象、时间、地点、责任和执行要求，避免把请示性内容写入通知。

## 请示

坚持一文一事，明确请示事项和拟请上级决定的内容，不夹带报告性事项。

## 报告

以陈述情况、反映问题和提出工作建议为主，不在报告中夹带需要批复的请示事项。

## 批复

逐项回应请示事项，结论明确，适用对象和执行要求清楚。

## 函

语气平等、克制，商洽事项和期望回复内容明确。

## 纪要

忠实反映议定事项、责任主体和完成时限，不把未形成共识的发言写成决定。

## 决定

事实依据、决定事项、适用对象和执行要求明确。

## 通报

事实准确、评价适度，表扬或批评均有可核验依据。
