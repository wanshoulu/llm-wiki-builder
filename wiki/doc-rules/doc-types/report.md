# 报告的文种规范

适用：向上级机关汇报工作、反映情况、回复上级机关的询问。行文方向：上行。doc_type: report，格式档案：gov。

## 标题

- "关于＋事由＋的报告"；工作报告可加时限："2026年上半年工作报告"。

## 行文规则

- 上行文须标注签发人。
- 报告不得夹带请示事项（CHK-DIR-003，P0）——需要请示的另文请示。
- 报告中不得出现资金请示表述（"请求拨款""请予安排经费"等）。

## 正文要素

- 工作报告：基本情况—主要做法与成效—存在问题—下一步安排。
- 情况报告：事件经过—处置情况—原因分析—整改措施。
- 数据准确，成效用具体数据支撑，不用"巨大""空前"等夸张修饰。

## 结语

"特此报告"。缺失为 P2。

## 常见错误

- 报告结尾夹带"妥否，请批示"（请示语混入报告）。
- 成效描述全是形容词没有数据。
- 情况报告缺整改措施。
