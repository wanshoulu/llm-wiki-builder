# 请示的文种规范

适用：向上级机关请求指示、批准。行文方向：上行。doc_type: request，格式档案：gov。

## 标题

- "关于＋请示事项＋的请示"，事由中避免"申请""请求"字样堆叠（文种已含请求义）。
- 一文一事：一份请示只请示一个事项。

## 行文规则

- 只主送一个上级机关，不得多头主送（CHK-DIR-002，P1）。
- 不得越级请示；确需越级的应抄送被越过机关。
- 不得抄送下级机关。
- 上行文须标注签发人。

## 正文要素

- 请示缘由：背景、依据、必要性，充分但不铺陈。
- 请示事项：明确、具体、可批复；涉及资金的写明金额与测算。
- 结语必须含请批语："妥否，请批示""以上请示，请予批复"等，缺失为 P0。

## 常见错误

- 一文多事（资金与机构设置混在一份请示）。
- 结语用"特此报告"或缺失请批语。
- 多头主送两个以上上级机关。
