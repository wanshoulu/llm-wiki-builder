# 版记与结语规范

## 正文结语

各文种规范结语（任一变体即合规，缺失由 CHK-END-* 检查）：

| 文种 | 结语 |
| --- | --- |
| 通知 | 特此通知 |
| 请示 | 妥否，请批示（或"以上请示，请予批复"等） |
| 报告 | 特此报告 |
| 函 | 特此函达 / 特此函复 / 请予函复 / 专此函达 |
| 批复 | 此复 / 特此批复 |
| 通报 | 特此通告 |
| 公告 | 特此公告 |

结语置于落款之前，独立成段，不加标点（"妥否，请批示"内部逗号除外）。

## 落款

- 发文机关署名：全称或规范化简称，右空二字。
- 成文日期：2026年11月1日 格式，阿拉伯数字，右空四字。
- 印章：端正、居中下压成文日期（"骑年盖月"惯例为下压日期）。

## 版记

- 抄送机关：四号仿宋，"抄送：XXX、XXX。"末尾句号。
- 印发机关和印发日期：版记末条，印发日期早于成文日期为错误。
