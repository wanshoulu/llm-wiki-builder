## 结语规则

| 文种 | 规范结语（任一即合规） | 缺失严重级 |
| --- | --- | --- |
| notice | 特此通知 | P2 |
| request | 妥否，请批示 / 以上请示，请予批复 / 请予批复 / 请批示 / 请批复 | P0 |
| report | 特此报告 | P2 |
| letter | 特此函达 / 特此函复 / 请予函复 / 专此函达 | P2 |
| reply | 此复 / 特此批复 | P2 |
| bulletin | 特此通告 | P2 |
| announcement | 特此公告 | P2 |

结语插于落款（发文机关+成文日期）之前。

## 评分规则

- P0 扣 25 分且一票否决（总分≥60 但有 P0 仍不通过）；P1 扣 8 分；P2 扣 3 分；满分 100，≥60 通过。
