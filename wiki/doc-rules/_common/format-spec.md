# 格式规范总纲

依据 GB/T 9704-2012《党政机关公文格式》。银行公文在国标基础上按档案参数微调（见 format-profiles）。

## 版面

- 页面 A4（210mm × 297mm）。
- 页边距（gov 档案）：上 37mm、下 35mm、左 28mm、右 26mm，容差 ±2mm。
- 版心每面 22 行、每行 28 字；行距 26-32 磅。

## 文字

- 大标题：方正小标宋简体二号（22pt），居中。
- 一级标题（一、）：黑体三号。二级标题（（一））：楷体_GB2312 三号。
- 正文：仿宋_GB2312 三号（16pt），两端对齐，每段首行左空二字。
- 正文不得加粗（gov 档案）；字号容差 ±1pt。

## 版头与落款

- 发文机关标志（红头）+ 发文字号〔YYYY〕N号 用六角括号。
- 成文日期用阿拉伯数字标全年月日；落款为发文机关全称或规范化简称。
- 附件说明在正文之后、落款之前："附件：1.XXX"。
