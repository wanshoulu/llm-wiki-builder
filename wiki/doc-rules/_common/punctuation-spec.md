# 标点与数字规范

## 标点符号

依据 GB/T 15834-2011《标点符号用法》。

- 公文正文使用全角标点；中文语境下半角句点、逗号、冒号均为错误。
- 序号标点层级："一、""（一）""1.""（1）"。一级用顿号、三级用下脚点；二级、四级括号后不加任何标点。
- 书名号、引号内不再套同类引号；发文字号年份用六角括号〔〕，不用圆括号或方括号。
- 句内并列成分用顿号；句子之间用句号，一逗到底为错误。

## 数字用法

依据 GB/T 15835 出版物数字用法，结合公文实务。

- 成文日期与结构层次序数用阿拉伯数字：2026年11月1日。
- 定型词组中的汉字数字保留：一律、三天三夜、"十四五"。
- 分数与小数：统计数字用阿拉伯数字；修约数字保留规定位数。

## 常见错误

| 错误示例 | 正确示例 |
| --- | --- |
| 一. 加强领导 | 一、加强领导 |
| （一）、提高认识 | （一）提高认识 |
| 2026/11/01 | 2026年11月1日 |
| 二０二六年十一月一日 | 2026年11月1日 |
| 〔2026〕写成 (2026) 或 [2026] | 〔2026〕 |
