# 版头规范

依据 GB/T 9704-2012 §7.1-7.2。

## 要素与顺序

1. 份号（涉密公文标注）
2. 密级和保密期限
3. 紧急程度
4. 发文机关标志（红头，居中）
5. 发文字号：机关代字＋〔年份〕＋序号，如"银发〔2026〕15号"，六角括号
6. 签发人（上行文需标注，位于发文字号同行右侧）

## 常见错误

| 错误 | 正确 |
| --- | --- |
| 银发(2026)15号 / 银发[2026]15号 | 银发〔2026〕15号 |
| 上行文缺签发人 | 请示/报告须标注签发人 |
| 份号用"第01号" | 直接标注 6 位数字 000001 |
