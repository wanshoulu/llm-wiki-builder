## 设计原则
1. 安全优先：高风险操作需二次确认，生物识别贯穿核心交易流程
2. 极简交互：核心交易 3 步以内完成，减少用户输入
3. 一致性：全局统一设计语言，组件复用率 > 80%
4. 无障碍：满足 WCAG 2.1 AA 级标准，支持大字体与高对比度

## 组件规范
### 1. 导航组件
- 底部 Tab 栏：5 个一级入口（首页/转账/理财/贷款/我的）
- 顶部导航栏：标题 + 返回 + 操作按钮，高度 56dp
- 侧滑菜单：二级入口折叠展开

### 2. 交易组件
- 金额输入框：大数字键盘，支持千分位与币种符号
- 收款人选择：智能推荐（最近转账/常用联系人），支持通讯录导入
- 确认弹窗：交易摘要 + 生物识别 + 确认按钮

### 3. 卡片组件
- 账户卡片：余额 + 最近交易 + 快捷操作
- 理财产品卡片：收益率 + 期限 + 风险等级 + 购买按钮
- 消息卡片：分类标签 + 标题 + 时间 + 操作

## 交互规范
- 页面转场：左滑进入/右滑返回，动画时长 300ms
- 加载状态：骨架屏优先，数据加载 < 500ms 不显示 loading
- 错误处理：友好提示 + 重试按钮，不暴露技术错误信息
- 生物识别：指纹优先→人脸降级→密码兜底

## 适配规范
- 分辨率：适配 360dp-414dp 主流宽度
- 暗色模式：全局色值定义暗色映射，支持跟随系统
- 大字体：支持系统字体放大 1.0x-1.5x，布局自适应
