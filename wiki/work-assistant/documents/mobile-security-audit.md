## 关键审计项
### 1. 身份认证
- 指纹 + 人脸双因子认证实现方案 ✓（已选型）
- 设备指纹采集与绑定 ✓
- 生物识别数据本地存储（不上传服务端）✓

### 2. 数据传输安全
- TLS 1.3 加密：新接口已支持，存量接口需 12 月前完成迁移
- 证书固定（Certificate Pinning）：需补充
- 传输数据完整性校验：已有

### 3. 交易安全
- 高风险交易实时风控拦截：需对接智能风控项目接口
- 单笔限额动态调整：需在改版中实现
- 异常交易告警：已有，需优化规则

### 4. 第三方安全
- SDK 安全审计频次：从年度提升至半年度 ✓
- 第三方组件清单与漏洞扫描：需建立流程
